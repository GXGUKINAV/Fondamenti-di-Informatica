1. Prima si progetta, poi si scrive il codice

Il messaggio iniziale del professore è: un algoritmo va pensato prima di mettersi alla tastiera. Scrivere direttamente codice, senza una visione complessiva, rischia di produrre una soluzione incompleta o difficile da correggere.

Quando un problema è troppo articolato per essere risolto tutto insieme, conviene:

  1. individuare gli ingressi e i risultati richiesti;
  2. descrivere a grandi linee i passaggi della soluzione;
  3. suddividere i passaggi complessi in sottoproblemi;
  4. dettagliare ogni sottoproblema;
  5. assemblare e verificare la soluzione completa.

Nelle slide, per esempio, il problema della sostituzione di una parola in un testo viene scomposto in lettura delle parole, memorizzazione negli array, confronto e scrittura del risultato. Le parti ancora da sviluppare vengono inizialmente indicate con descrizioni tra parentesi quadre: sono segnaposto nello pseudocodice, non istruzioni C.

Il significato di «divide et impera» in questa lezione

Il professore usa l'espressione per indicare l'idea di «fare a fette» un problema, conservando però una visione d'insieme: prima si descrive la soluzione complessiva, poi si approfondiscono i singoli pezzi.

Una soluzione funzionante non è necessariamente la migliore

Il lavoro non termina appena il programma sembra funzionare. Bisogna chiedersi:

  • fa davvero ciò che richiede il problema?
  • funziona anche nei casi limite?
  • ci sono passaggi inutili?
  • si può rendere più chiaro o più efficiente?

Lo stesso spirito critico va mantenuto quando si usa un'IA generativa: il codice ricevuto non deve essere accettato automaticamente, ma compreso e verificato.

2. Dal progetto al programma eseguibile

Il percorso presentato a lezione è:

progettazione dell'algoritmo → scrittura del codice C → compilazione → produzione dell'eseguibile → esecuzione e verifica.

Il compilatore controlla il codice e lo traduce, ma una compilazione riuscita non dimostra che l'algoritmo sia corretto. Un programma può essere sintatticamente valido e calcolare comunque un risultato sbagliato.

Errori e warning

DiagnosticaSignificatoConseguenza tipica
ErroreIl compilatore rileva un problema che impedisce di completare correttamente la compilazioneNon si ottiene un nuovo eseguibile valido
WarningIl compilatore segnala qualcosa di sospetto o problematicoLa compilazione può continuare

Esempi discussi: usare una variabile non dichiarata provoca un errore; dichiarare una variabile e non usarla può produrre un warning. I warning non vanno ignorati a priori: alcuni segnalano problemi importanti, anche se non bloccano la compilazione.

3. Struttura fondamentale di un programma C

Una struttura di riferimento (somma di due interi, come nelle slide) è:

#include <stdio.h>

int main(void)
{
  /* Parte dichiarativa */
  int a, b, somma;

  /* Parte esecutiva */
  printf("Inserisci due numeri interi:\n");
  scanf("%d%d", &a, &b);
  somma = a + b;
  printf("La somma e': %d\n", somma);
  return 0;
}

Per ora si assume che l'utente inserisca dati validi; il controllo dell'esito di scanf viene spiegato più avanti. Le parti principali sono:

  • direttive del preprocessore: per esempio #include;
  • funzione main: punto d'ingresso del programma;
  • parte dichiarativa: variabili e costanti;
  • parte esecutiva: istruzioni che realizzano l'algoritmo.
Precisazione importante: int main(void), non void main()

Nella spiegazione orale e in alcune slide compare void main(). Per i normali programmi eseguiti sotto un sistema operativo, la forma standard da usare è:

int main(void)
{
  return 0;
}

int indica il tipo del valore restituito; void dentro le parentesi indica che non ci sono parametri; return 0; comunica una terminazione riuscita. void main() non è un'alternativa standard equivalente: alcuni compilatori possono accettarla come estensione.

Commenti

/* Questo e' un commento */

/*
  Questo commento
  occupa piu' righe.
*/

Servono a spiegare il codice, soprattutto le scelte non ovvie. Non sono istruzioni da eseguire.

4. Il preprocessore e #include

La direttiva #include <stdio.h> fa includere al preprocessore il contenuto dell'header stdio.h, che contiene, tra le altre cose, le dichiarazioni di printf e scanf. La relazione da ricordare è:

  1. #include <stdio.h>;
  2. il compilatore conosce le dichiarazioni di printf e scanf;
  3. possiamo usarle correttamente nel nostro codice.
Header e libreria non sono la stessa cosa

Dire «includiamo la libreria» è una semplificazione. Più precisamente includiamo un file header: stdio.h fornisce le dichiarazioni necessarie, non una copia di tutta l'implementazione di printf e scanf.

Le direttive del preprocessore non sono normali istruzioni esecutive e non richiedono il punto e virgola finale:

#include <stdio.h>
#define DIMENSIONE 100

Entrambe operano prima della compilazione vera e propria.

5. Variabili, dichiarazioni e tipi

Prima di usare una variabile bisogna dichiararla, specificandone tipo e nome:

int numero;
float temperatura;
char carattere;

Più variabili dello stesso tipo possono essere dichiarate insieme:

int numero, somma, contatore;

Il tipo della variabile resta lo stesso durante la sua vita: una variabile dichiarata int non diventa successivamente float.

Dichiarare e inizializzare sono due cose diverse

int somma;       /* Dichiarazione */
somma = 0;       /* Assegnamento di un valore iniziale */

int somma = 0;   /* Dichiarazione con inizializzazione */

Il professore suggerisce di raccogliere le dichiarazioni all'inizio del programma, così da rendere subito visibili le variabili impiegate.

Attenzione ai nomi

Maiuscole e minuscole sono distinte: somma, Somma e SOMMA sono tre identificatori diversi. Scrivere un nome diverso da quello dichiarato può causare un errore.

6. Che cos'è un tipo di dato?

Definizione — Tipo di dato

Un tipo di dato definisce:

  1. un insieme di valori;
  2. un insieme di operazioni applicabili a quei valori.

Per esempio, un tipo intero stabilisce quali numeri sono rappresentabili e quali operazioni si possono eseguire. Il tipo è anche un'astrazione: possiamo scrivere 23 + 74 senza dover conoscere, ogni volta, la rappresentazione in bit e l'algoritmo interno della somma.

Classificazione

Tipi predefinitiTipi già disponibili nel linguaggioNon dobbiamo costruirli noi
Tipi definiti dall'utenteEnumerazioni, alias con typedefDescrivono meglio i dati del problema

  • Virgola mobile: double, long double.

Le varianti modificano caratteristiche come intervallo rappresentabile e precisione. Non bisogna però immaginare che ogni passaggio garantisca sempre il raddoppio dello spazio: nelle slide le dimensioni sono indicate con relazioni «minore o uguale».

8. Costanti con const

Se un valore non deve cambiare durante l'esecuzione, si può dichiarare un oggetto const:

const float PI_GRECO = 3.1415f;
const int SOGLIA = 100;
const char TERMINATORE = '#';

Un successivo assegnamento come SOGLIA = 200; non è consentito.

Perché usare un nome invece di ripetere il numero?

Se un valore compare molte volte nel codice, assegnargli un nome:

  • rende più chiaro il suo significato;
  • evita ripetizioni incoerenti;
  • permette di modificarlo in un unico punto.

L'esempio della lezione è $\pi$: se si decide di cambiarne l'approssimazione, si modifica la dichiarazione invece di cercare ogni occorrenza numerica nel programma.

9. Output con printf

printf è una funzione di libreria per scrivere sullo standard output, normalmente lo schermo.

Stampa di testo

printf("Ciao!\n");

La stringa è delimitata dalle virgolette doppie; \n provoca un salto alla riga successiva.

Stampa di valori

int eta = 19;
printf("Hai %d anni.\n", eta);

%d è uno specificatore di formato: viene sostituito dalla rappresentazione del valore passato dopo la stringa.

Formati principali

FormatoCosa si stampa
%dIntero decimale
%fNumero in virgola mobile in notazione decimale
%eNumero in notazione scientifica
%cCarattere
%sStringa

L'associazione è posizionale

printf("Numero: %d; carattere: %c\n", numero, carattere);

Il primo formato corrisponde al primo argomento dopo la stringa, il secondo al secondo. Gli argomenti possono anche essere espressioni:

printf("La somma e': %d\n", a + b);

Non è obbligatorio creare una variabile somma solo per stampare il risultato.

Carattere e codice numerico

Nel contesto ASCII della lezione:

char c = 'A';
printf("%c\n", c);   /* Stampa A */
printf("%d\n", c);   /* Stampa 65 */

Lo stesso valore viene visualizzato come carattere oppure come numero.

10. Input con scanf

scanf legge dati dallo standard input, normalmente la tastiera, e li memorizza nelle destinazioni indicate.

int numero;
printf("Inserisci un numero: ");
scanf("%d", &numero);

Che cosa significa &numero?

&numero significa «indirizzo della variabile numero». La distinzione è:

printf("%d", numero);    /* Uso il valore */
scanf("%d", &numero);    /* Indico dove scrivere il valore letto */

scanf deve poter modificare la variabile: per questo riceve il suo indirizzo.

Formati per la lettura

VariabileLettura
int numero;scanf("%d", &numero);
float x;scanf("%f", &x);
double y;scanf("%lf", &y);
char c;scanf("%c", &c);

Attenzione soprattutto alla differenza tra %f e %lf nell'input: la destinazione deve avere il tipo corretto.

Lettura di più valori

char c;
int i;
float x;
scanf(" %c%d%f", &c, &i, &x);

Un ingresso possibile è A 3 7.345. I valori vengono assegnati nell'ordine a c, i e x. Una sola chiamata può leggere più valori; non significa però che tutti debbano essere digitati sulla stessa riga.

scanf non stampa messaggi

Questo non mostra nessuna richiesta all'utente:

scanf("Inserisci un numero: %d", &numero);

La forma corretta è:

printf("Inserisci un numero: ");
scanf("%d", &numero);

Precisazione: la stringa di formato di scanf può contenere anche caratteri letterali, ma questi devono corrispondere all'ingresso; non vengono stampati. Per esempio, "%d,%d" può descrivere due interi separati da una virgola.

Controllare se la lettura è riuscita

scanf restituisce il numero di valori assegnati con successo. Per leggere un solo intero:

if (scanf("%d", &numero) != 1)
{
  printf("Input non valido.\n");
  return 1;
}

Questo controllo evita di proseguire dando per acquisito un numero che magari non è stato letto. È una precisazione pratica rispetto agli esempi introduttivi, che assumono ingressi corretti.

11. Il buffer di input: perché %c sembra «saltare» una lettura?

Questo è uno dei punti più importanti della lezione. Consideriamo:

char primo, secondo;
scanf("%c", &primo);
scanf("%c", &secondo);

Se si digita A + Invio, nell'ingresso troviamo concettualmente 'A' e '\n'. La prima scanf legge 'A'. La seconda legge subito '\n', che era rimasto nell'ingresso: non ha bisogno di attendere un altro carattere.

Soluzione quando vogliamo un carattere non bianco

scanf(" %c", &secondo);

Lo spazio prima di %c fa consumare gli eventuali caratteri bianchi iniziali (spazi, tabulazioni, a capo) prima di leggere il carattere richiesto.

FormatoComportamento
"%c"Legge il prossimo carattere, anche se è uno spazio o un a capo
" %c"Salta i caratteri bianchi iniziali e legge il prossimo carattere non bianco
Non è una «pulizia completa del buffer»

Gli altri caratteri già presenti restano disponibili e possono essere letti subito.

Perché con gli interi spesso non succede?

Formati come %d e %f saltano già i caratteri bianchi iniziali; %c non lo fa automaticamente. Quindi due letture consecutive:

scanf("%d", &a);
scanf("%d", &b);

non hanno bisogno dello spazio aggiuntivo soltanto per gestire l'a capo tra due numeri. Se invece lo spazio o l'a capo è proprio il dato che vuoi leggere, devi mantenere "%c" senza spazio iniziale.

12. Operazioni sugli interi

OperatoreSignificato
=Assegnamento
+, -, *Somma, sottrazione, moltiplicazione
/Divisione
%Resto della divisione intera
==, !=Uguaglianza e diversità
<, >, <=, >=Confronti
= e == non sono intercambiabili
numero = 5;     /* Assegna 5 */
numero == 5     /* Verifica se il valore e' 5 */

Divisione intera

Se entrambi gli operandi sono interi, il risultato della divisione è intero, e la parte frazionaria viene scartata:

7 / 2    /* Risultato: 3 */
7 % 2    /* Risultato: 1 */
Esempio — float risultato = 7 / 2;
float risultato;
risultato = 7 / 2;

Il risultato memorizzato è 3.0, non 3.5: la divisione viene calcolata prima, usando due interi. Il tipo della destinazione non cambia retroattivamente l'operazione. Per ottenere il risultato frazionario:

risultato = 7.0f / 2;

Perché dividere e poi moltiplicare può non restituire il numero iniziale?

Esempio della lezione: int a = 7; int b = 3;. L'espressione (a / b) * b vale (7 / 3) * 3, cioè 2 * 3, cioè 6. Quindi non coincide con a. Per questi interi positivi, l'identità torna quando $a$ è divisibile per $b$: il punto non è, in generale, che $a$ sia pari o dispari.

13. Numeri in virgola mobile e precisione

float e double rappresentano un'approssimazione dei numeri reali, usando uno spazio finito. Non possono quindi garantire precisione infinita. Si possono scrivere valori in notazione decimale (3.14, 0.000076) oppure scientifica: 7.6e-5 significa

$$7.6\times10^{-5}.$$

Cambiare notazione non rende il numero più preciso: cambia il modo in cui lo scriviamo o visualizziamo.

Due numeri stampati uguali possono essere diversi

float x = 4.56147f;
float y = 4.56148f;

I valori sono diversi, anche se una visualizzazione con poche cifre decimali potrebbe farli apparire uguali. Bisogna distinguere il valore memorizzato dal testo mostrato a schermo.

Confronto con tolleranza

Invece di chiedere un'uguaglianza esatta, il problema può richiedere che i valori siano abbastanza vicini:

$$|x-y|\le\varepsilon.$$

La lezione propone questa forma, per valori finiti e una tolleranza positiva:

if (x <= y + 0.01 && y <= x + 0.01)
{
  printf("Simili\n");
}

Le due condizioni limitano la differenza in entrambe le direzioni.

Che cosa significa 0.01?

È una tolleranza assoluta: accettiamo una differenza non superiore a 0.01. Non significa automaticamente «1%», né garantisce che le prime due cifre decimali siano identiche. Per esempio, 1.999 e 2.001 differiscono soltanto di 0.002, pur trovandosi ai due lati di un intero. La tolleranza va scelta in base al problema: non esiste un valore unico adatto a tutti gli esercizi.

Funzioni matematiche

Le slide citano le funzioni sqrt (radice quadrata), pow (potenza), exp (esponenziale), sin, cos, tan (trigonometriche). Le versioni presentate lavorano su double; il relativo header è math.h. Il nome della funzione per la potenza è pow, non power.

Un carattere si scrive tra apici singoli ('A'), una stringa tra virgolette doppie ("A").

Anche se \n è scritto con due simboli nel codice sorgente, rappresenta un singolo carattere.

Riconoscere lettere e cifre nel contesto ASCII

Non serve confrontare il carattere con tutte le 26 lettere. Si sfrutta l'ordinamento dei codici ASCII:

/* Maiuscola */
if (c >= 'A' && c <= 'Z')
{
  printf("Lettera maiuscola\n");
}

/* Minuscola */
if (c >= 'a' && c <= 'z')
{
  printf("Lettera minuscola\n");
}

/* Cifra */
if (c >= '0' && c <= '9')
{
  printf("Cifra\n");
}

Per le cifre, il confronto va fatto con '0' e '9', non con gli interi 0 e 9.

Conversione da minuscola a maiuscola

maiuscola = c - ('a' - 'A');

La distanza tra una lettera minuscola e la corrispondente maiuscola è costante e vale 32. Usare 'a' - 'A' esprime il significato dell'operazione meglio di un numero isolato. La conversione va effettuata dopo aver verificato che c sia una minuscola:

if (c >= 'a' && c <= 'z')
{
  maiuscola = c - ('a' - 'A');
}

Sommare caratteri significa fare aritmetica sui loro codici: non significa concatenarli in una parola.

15. Esempio completo: somma fino allo zero

Il problema è leggere numeri interi e sommarli finché viene inserito 0, che funge da sentinella, cioè da valore di terminazione. Questa versione aggiunge il controllo dell'input agli esempi della lezione:

#include <stdio.h>

int main(void)
{
  int numero, somma;

  somma = 0;
  printf("Inserisci un numero, 0 per terminare: ");
  if (scanf("%d", &numero) != 1)
  {
    printf("Input non valido.\n");
    return 1;
  }

  while (numero != 0)
  {
    somma = somma + numero;
    printf("Inserisci un numero, 0 per terminare: ");
    if (scanf("%d", &numero) != 1)
    {
      printf("Input non valido.\n");
      return 1;
    }
  }

  printf("La somma e': %d\n", somma);
  return 0;
}

La lettura iniziale permette di controllare subito la condizione del while. La lettura dentro il ciclo acquisisce il dato dell'iterazione successiva. Se il primo numero è 0, il corpo del ciclo non viene eseguito e la somma resta zero.

16. typedef: dare un nome a un tipo

La sintassi di base è:

typedef tipoEsistente nuovoNome;
Esempio — alias di int
typedef int anno;
anno annoNascita;
anno annoCorrente;

anno è un alias di int: permette di esprimere meglio il significato delle variabili, ma non introduce automaticamente nuovi vincoli.

Quindi anno x = -10; non viene vietato soltanto perché abbiamo chiamato il tipo anno. Se il problema richiede anni positivi o un intervallo particolare, bisogna verificarlo nel programma.

Che cosa non fa typedef? Non definisce automaticamente nuove operazioni, né costruisce da solo un nuovo tipo astratto completo. Le slide sottolineano proprio questa limitazione.

17. Enumerazioni: enum

Un'enumerazione permette di definire costanti simboliche legate a valori interi.

typedef enum
{
  lun,
  mar,
  mer,
  gio,
  ven,
  sab,
  dom
} giornoDellaSettimana;

giornoDellaSettimana oggi;
oggi = mer;

mer non è una stringa: è una costante dell'enumerazione, quindi si usa senza virgolette.

Valori assegnati automaticamente

Non essendo specificati valori espliciti: lun = 0, mar = 1, mer = 2, gio = 3, ven = 4, sab = 5, dom = 6. Perciò lun < ven è vero in base ai valori numerici associati. L'ordine dell'enumerazione non implica automaticamente un significato universale: se definiamo colori, il confronto dipende dall'ordine in cui li abbiamo elencati.

Booleani nell'impostazione del corso

typedef enum
{
  falso,
  vero
} boolean;

In questo modo falso = 0 e vero = 1. L'ordine è importante perché nelle condizioni C:

  • zero significa falso;
  • qualsiasi valore diverso da zero significa vero, anche se negativo.
L'ordine dei nomi conta
typedef enum{
  vero,
  falso
} boolean;

Qui vero avrebbe valore 0, cioè sarebbe falso nelle condizioni: il nome scelto non cambia il significato numerico.

18. Array monodimensionali

Un array è una sequenza di elementi dello stesso tipo, accessibili tramite un indice.

int numeri[5];

Dichiara cinque elementi:

Indice01234
Elemento[ ][ ][ ][ ][ ]

Gli indici validi vanno da $0$ a $N-1$, non da $1$ a $N$.

Accesso agli elementi

numeri[0] = 10;
numeri[1] = 20;
printf("%d\n", numeri[0]);
scanf("%d", &numeri[2]);

Un singolo elemento si usa come una variabile del tipo contenuto nell'array.

Dimensione e quantità di dati usati sono diverse

Supponiamo int numeri[100]; ma di aver inserito soltanto sette numeri.

  • Capacità: 100 elementi.
  • Elementi effettivamente usati: 7.
  • Ultimo indice occupato: 6.

Serve quindi una variabile che tenga conto della quantità di dati memorizzati. Per stampare al contrario si parte dall'ultimo elemento occupato, non necessariamente dall'ultima posizione disponibile.

Dimensione fissa non significa che devi riempirlo tutto

L'array non cresce automaticamente quando serve altro spazio. Se è stato creato con 100 elementi, puoi usarne meno, ma non puoi trattarlo come se ne avesse 101. Il compromesso illustrato a lezione è scegliere una capacità sufficiente, sapendo che una parte potrebbe restare inutilizzata.

Array e typedef

typedef int vettore[20];
vettore lista1, lista2;

Definisce un nome riutilizzabile per il tipo «array di 20 interi». Per queste due variabili si può anche scrivere direttamente int lista1[20], lista2[20];. Il vantaggio dell'alias aumenta quando il tipo deve essere riutilizzato o quando il suo nome chiarisce il significato dei dati.

19. Array multidimensionali

Un array bidimensionale si può leggere come una matrice:

int matrice[3][4];

Ha 3 righe, 4 colonne e 12 elementi. Per accedere a un elemento servono due indici:

matrice[1][2] = 7;

Gli indici ammessi sono da 0 a 2 per la prima dimensione e da 0 a 3 per la seconda. Una matrice non deve necessariamente essere quadrata.

Tre dimensioni

int dati[10][20][30];
dati[2][8][15] = 42;

Servono tre indici perché l'array ha tre dimensioni. In generale, ogni dimensione aggiunge un indice per identificare il singolo elemento.

20. Stringhe: il collegamento con gli array

Nel C non esiste un tipo fondamentale string come in altri linguaggi. Le stringhe C vengono rappresentate mediante sequenze di caratteri terminate da '\0'.

char nome[5] = "Luca";

La disposizione è 'L' 'u' 'c' 'a' '\0'. Per contenere una stringa di quattro caratteri servono dunque cinque posizioni, includendo il terminatore.

Questo non significa che ogni array di caratteri sia automaticamente una stringa: il terminatore deve essere presente se vogliamo usarlo come stringa C.

21. #define: evitare numeri ripetuti nel codice

#define LUNGHEZZA 100

definisce una macro. Il preprocessore sostituisce le occorrenze appropriate di LUNGHEZZA con 100 prima della compilazione. Possiamo quindi scrivere:

int numeri[LUNGHEZZA];
...
while (i < LUNGHEZZA)

Per cambiare la capacità, modifichiamo soltanto #define LUNGHEZZA 200 e ricompiliamo. Questo evita di aggiornare a mano tanti numeri sparsi, rischiando di dimenticarne qualcuno.

Non mettere = o ;

Forma corretta: #define LUNGHEZZA 100. Non: #define LUNGHEZZA = 100;. La macro è una sostituzione effettuata dal preprocessore, non una dichiarazione di variabile.

Per gli array a dimensione nota dell'impostazione del corso, #define è quindi una scelta coerente. È anche meglio non ridurre la distinzione a «const occupa sempre memoria fisica»: la differenza centrale riguarda il modello del linguaggio, non una garanzia su come verrà ottimizzato l'eseguibile.

22. Esempio completo: lettura e stampa inversa di un array

Questo esempio riprende il programma delle slide con capacità definita tramite macro e aggiunge il controllo delle letture.

#include <stdio.h>

#define LUNGHEZZA 5

int main(void)
{
  int numeri[LUNGHEZZA];
  int i;

  i = 0;
  while (i < LUNGHEZZA)
  {
    printf("Inserisci il numero %d: ", i + 1);
    if (scanf("%d", &numeri[i]) != 1)
    {
      printf("Input non valido.\n");
      return 1;
    }
    i = i + 1;
  }

  i = i - 1;
  printf("Numeri in ordine inverso:\n");
  while (i >= 0)
  {
    printf("%d\n", numeri[i]);
    i = i - 1;
  }

  return 0;
}

Perché i = i - 1 tra i due cicli?

Dopo la lettura di cinque numeri, i vale 5. Ma gli elementi validi sono numeri[0], numeri[1], numeri[2], numeri[3], numeri[4]. Prima della stampa dobbiamo quindi portare l'indice da 5 a 4, l'ultimo elemento. Il ciclo termina dopo aver stampato anche l'elemento in posizione 0.

23. Checklist per il ripasso

Cose da saper spiegare e applicare
  • Progettare la soluzione prima di scrivere codice.
  • Distinguere compilazione riuscita e correttezza dell'algoritmo.
  • Dichiarare una variabile prima di usarla.
  • Distinguere dichiarazione, inizializzazione e assegnamento.
  • Distinguere = da ==.
  • Usare i formati corretti in printf e scanf.
  • Passare a scanf l'indirizzo della destinazione.
  • Capire perché "%c" legge anche un a capo.
  • Usare " %c" quando si vogliono saltare i caratteri bianchi.
  • Ricordare che la divisione tra interi produce un risultato intero.
  • Distinguere uguaglianza esatta e confronto con tolleranza.
  • Distinguere caratteri, stringhe e identificatori.
  • Usare i confronti sugli intervalli ASCII invece di 26 confronti separati.
  • Capire che typedef dà un alias, senza aggiungere automaticamente vincoli.
  • Capire che i nomi di un'enumerazione hanno valori numerici.
  • Gestire gli indici degli array da 0 a $N-1$.
  • Distinguere capacità dell'array e numero di elementi utilizzati.
  • Usare #define per tenere coerenti dimensioni e limiti dei cicli.
