1. Il filo logico della lezione

La lezione mette insieme tre modi diversi di organizzare e usare i dati:

  • Array: raggruppano elementi dello stesso tipo.
  • struct: raggruppano campi che possono avere tipi diversi.
  • Puntatori: permettono di accedere ai dati attraverso il loro indirizzo in memoria.

Il passaggio centrale è la differenza tra copiare un valore e copiare un riferimento a quel valore: nel secondo caso non si crea un secondo dato, ma un altro modo per raggiungere lo stesso dato.

Imprecisioni nella spiegazione orale

Durante la lezione alcuni passaggi, soprattutto sull'assegnamento tra array, confondono array e puntatori. Questi appunti riportano la versione corretta, segnalando dove non conviene prendere alla lettera la spiegazione orale.

2. Ripasso sugli array

Un array è una sequenza di elementi dello stesso tipo, accessibili tramite un indice.

int numeri[5];

Crea cinque elementi di tipo int, con indici da 0 a 4. In generale, con $N$ elementi gli indici validi vanno da $0$ a $N-1$: per questo il ciclo tipico usa i < N e non i <= N.

for (int i = 0; i < 5; i++) {
  numeri[i] = i + 1;
}

Risultato: numeri = [1, 2, 3, 4, 5].

Definire un tipo array con typedef

typedef int Vettore[5];
Vettore numeri;
Vettore altriNumeri;

Vettore è il nome del tipo; numeri e altriNumeri sono le variabili. Dare un nome al tipo rende più chiaro il significato dei dati.

Usare #define per le dimensioni

#define DIM 5
int numeri[DIM];

Il preprocessore sostituisce DIM con 5 prima della compilazione. Se la dimensione cambia, si modifica un solo punto del codice.

Niente punto e virgola nella macro
#define DIM 5     /* Corretto */
#define DIM 5;    /* Sbagliato per questo utilizzo */

Nel secondo caso anche il ; entra nel testo sostituito e rovina espressioni come int numeri[DIM];.

3. Copiare un array: cosa si può fare davvero

int a[3] = {10, 20, 30};
int b[3];

b = a;   /* ERRORE */

In C non si può assegnare direttamente un intero array a un altro array. Non si ottiene né una copia né due nomi per lo stesso array: si ottiene un errore di compilazione.

Copia elemento per elemento

for (int i = 0; i < 3; i++) {
  b[i] = a[i];
}

Dopo la copia a e b valgono entrambi [10, 20, 30], ma sono indipendenti: dopo b[0] = 99; si ha a = [10, 20, 30] e b = [99, 20, 30]. Si sono copiati i valori, non condivisi gli elementi.

4. Esercizio: concatenare due sequenze in ordine alfabetico

Richiesta
  1. Leggere due sequenze di esattamente 50 caratteri.
  2. Capire quale precede l'altra nell'ordinamento.
  3. Copiarle in un terzo array, mettendo prima quella che precede.
  4. Stampare il risultato.

Confronto: cercare il primo carattere diverso

Esempio con CASA e CANE:

  • C == C: continua;
  • A == A: continua;
  • S != N: si decide qui.

Nella codifica ASCII, 'N' < 'S', quindi CANE precede CASA. Il resto non serve: il primo carattere diverso determina l'ordine.

Non è un ordinamento linguistico

È un confronto basato sui codici dei caratteri: non gestisce automaticamente maiuscole, minuscole e accenti.

Il ciclo di confronto

i = 0;
while (i < N && a[i] == b[i]) {
  i++;
}

All'uscita ci sono due casi:

  • i == N: tutti i caratteri confrontati sono uguali;
  • i < N: i è la prima posizione con caratteri diversi.

La condizione i < N va messa prima dell'accesso agli elementi, così il confronto si ferma prima di uscire dai limiti dell'array. La scelta dell'ordine è:

if (i == N || a[i] < b[i]) {
  /* Copia prima a, poi b */
} else {
  /* Copia prima b, poi a */
}

Se le sequenze sono identiche, l'ordine di concatenazione non cambia il risultato.

Versione compatta

Il frammento presuppone che a e b contengano già $N$ caratteri.

#define N 50

char a[N], b[N];
char risultato[2 * N];
int i = 0;

while (i < N && a[i] == b[i]) {
  i++;
}

if (i == N || a[i] < b[i]) {
  for (int j = 0; j < N; j++) {
    risultato[j] = a[j];
    risultato[N + j] = b[j];
  }
} else {
  for (int j = 0; j < N; j++) {
    risultato[j] = b[j];
    risultato[N + j] = a[j];
  }
}

for (int j = 0; j < 2 * N; j++) {
  printf("%c", risultato[j]);
}

Array di caratteri e stringhe C non sono sempre la stessa cosa

Un array con 50 caratteri non è necessariamente una stringa C valida: una stringa deve terminare con '\0'. Per 50 caratteri di testo servono quindi 51 celle.

char parola[51];
scanf("%50s", parola);

%s aggiunge il terminatore e si ferma anche davanti a spazi o altri separatori: non equivale a leggere esattamente 50 caratteri con %c.

Attenzione a risultato[100]

Se tutte le 100 celle contengono caratteri del risultato, non c'è spazio per '\0'. La stampa carattere per carattere va bene; printf("%s", risultato); non è sicuro senza aggiungere e gestire il terminatore.

Variante con matrice

char sequenze[2][50];
  • sequenze[0]: prima sequenza;
  • sequenze[1]: seconda sequenza;
  • sequenze[1][3]: quarto carattere della seconda sequenza.

La matrice permette di usare cicli annidati e di ridurre il codice duplicato.

5. Le struct: dati eterogenei

Gli array contengono elementi dello stesso tipo. Una persona, invece, ha nome e cognome (sequenze di caratteri), stipendio (numero), data di assunzione (giorno, mese, anno). Per raggruppare informazioni di questo genere si usa una struttura (o record); in C la parola chiave è struct.

Definire un tipo Data

typedef struct {
  int giorno;
  int mese;
  int anno;
} Data;

Data oggi;
Data assunzione;
  • Data: nome del tipo;
  • oggi: variabile;
  • giorno, mese, anno: campi della struttura.

Accedere ai campi con il punto

oggi.giorno = 20;
oggi.mese = 10;
oggi.anno = 2026;

La forma generale è variabile.campo. Il campo deve esistere nella definizione del tipo: oggi.stipendio sarebbe un errore.

Strutture dentro altre strutture

typedef struct {
  char destinatario[101];
  double importo;
  Data dataEmissione;
} Fattura;

Fattura fattura;
fattura.importo = 150.50;
fattura.dataEmissione.giorno = 20;
fattura.dataEmissione.mese = 10;
fattura.dataEmissione.anno = 2026;

Ogni punto entra in un livello della struttura: fattura → dataEmissione → giorno, mese, anno. Il tipo Data deve essere già definito quando lo si usa come campo di Fattura.

Array e strutture si possono combinare

Array di strutture:

Fattura archivio[1000];
archivio[0].importo = 250.0;

Array dentro una struttura:

typedef struct {
  char nome[31];
  char cognome[31];
  double stipendio;
} Dipendente;

Dipendente dip;
if (dip.cognome[0] == 'A') {
  /* Il cognome inizia con A */
}

Nell'ultimo frammento si presume che il cognome sia già stato inizializzato. Gli operatori [] e . si combinano seguendo la forma dei dati.

Perché un numero di telefono si salva come testo?

Un numero di telefono è un identificatore, non una quantità su cui fare calcoli. Come sequenza di caratteri conserva, per esempio, lo zero iniziale del prefisso:

char telefono[21] = "0372123456";

La scelta del tipo dipende dal significato del dato, non dal fatto che contenga cifre.

6. Assegnamento tra strutture

Diversamente dagli array, due strutture dello stesso tipo si possono assegnare direttamente:

Dipendente dip1;
Dipendente dip2;

/* Si presume che dip1 sia già inizializzato. */
dip2 = dip1;

L'assegnamento copia tutti i campi, compresi gli eventuali array contenuti nella struttura: anche nome e cognome vengono copiati.

OperazioneRisultato
b = a, con a e b arrayNon consentita
dip2 = dip1, strutture dello stesso tipoCopia la struttura
p = q, puntatori compatibiliCopia il puntatore, non il dato puntato

Questa distinzione è il ponte verso la seconda parte della lezione.

7. Esercizio d'esame: rappresentare un'autovettura

Richiesta

Rappresentare un'autovettura con nome, marca, tipo di motore, numero di cilindri e un insieme di accessori. È un esercizio di progettazione del tipo di dato, non ancora di scrittura dell'algoritmo.

Una possibile rappresentazione, assumendo che il tipo Accessorio sia già definito:

#define MAX_NOME 20
#define MAX_MARCA 15
#define MAX_ACCESSORI 50

typedef enum {
  BENZINA,
  DIESEL
} TipoMotore;

typedef enum {
  QUATTRO,
  SEI,
  OTTO
} TipoCilindri;

typedef struct {
  char nome[MAX_NOME + 1];
  char marca[MAX_MARCA + 1];
  TipoMotore motore;
  TipoCilindri cilindri;
  Accessorio accessori[MAX_ACCESSORI];
  int numeroAccessori;
} Autovettura;
  • Il + 1 riserva lo spazio per '\0' nei campi usati come stringhe.
  • numeroAccessori distingue la capacità massima dell'array dagli elementi effettivamente presenti.
  • I nomi dell'enum non sono stringhe: senza assegnazioni esplicite, QUATTRO, SEI e OTTO valgono 0, 1 e 2, non 4, 6 e 8.

8. Puntatori: l'idea fondamentale

Una variabile contiene un valore; un puntatore può contenere l'indirizzo attraverso cui raggiungere una variabile.

int x = 37;
int *p = &x;
  • x contiene 37;
  • &x è l'indirizzo di x;
  • p contiene quell'indirizzo;
  • *p permette di accedere all'oggetto puntato, cioè x.

I due operatori da distinguere

EspressioneCome leggerla
xValore della variabile x
&xIndirizzo di x
pIndirizzo contenuto nel puntatore
*pOggetto raggiunto attraverso il puntatore

L'operatore & ricava un indirizzo; l'operatore *, usato in un'espressione, dereferenzia il puntatore.

L'asterisco nella dichiarazione e nell'uso

Nella dichiarazione int *p; si dichiara un puntatore a int. In un'istruzione, *p = 50; scrive nell'intero puntato. Gli spazi non cambiano il significato: int *p;, int* p; e int * p; sono equivalenti.

Più variabili in una dichiarazione
int *p, q;     /* p è un puntatore, q è un normale int */
int *p, *q;    /* due puntatori */

Non è la posizione grafica dell'asterisco a determinare il tipo: conta come è costruita la dichiarazione.

Scrivere attraverso un puntatore

int x = 37;
int *p = &x;
*p = 50;
printf("%d\n", x);   /* 50 */

*p e x identificano lo stesso oggetto: modificare l'uno significa modificare l'altro.

9. La differenza fondamentale: p = q e *p = *q

Situazione iniziale:

int x = 25;
int y = 38;
int *p = &x;
int *q = &y;

Cioè p punta a x (25) e q punta a y (38).

p = q: copia dell'indirizzo

Ora entrambi i puntatori raggiungono y.

  • Non si è copiato 38 dentro x;
  • si è cambiato il contenuto di p;
  • x esiste ancora (vale ancora 25) ed è accessibile con il proprio nome.

*p = *q: copia del valore puntato

Ripartendo dalla situazione iniziale, il valore di y viene copiato dentro x: x e y valgono entrambi 38, ma i puntatori continuano a raggiungere due variabili diverse.

Regola pratica

p = q copia il riferimento; *p = *q copia il valore.

I due esempi vanno letti come alternative a partire dalla stessa situazione iniziale, non come istruzioni consecutive.

10. Aliasing: due riferimenti allo stesso oggetto

Quando due puntatori raggiungono lo stesso oggetto si parla di aliasing.

int x = 3;
int y = 5;
int *p = &x;
int *q = &y;

p = q;
*q = 7;
printf("%d\n", *p);   /* 7 */

Dopo p = q, entrambi puntano a y: la modifica fatta tramite q è visibile anche tramite p. Non sono due copie che si aggiornano magicamente: il dato è uno solo.

Con variabili indipendenti succede invece questo:

int x = 3;
int y = 5;
x = y;
y = 7;
printf("%d\n", x);   /* 5 */

La copia di un valore non crea un collegamento permanente tra le variabili.

11. Perché scanf vuole &?

Per scrivere il valore letto dentro una variabile, scanf deve ricevere l'indirizzo della destinazione.

int numero;
scanf("%d", &numero);

%d richiede la conversione per un intero; &numero indica dove memorizzarlo. Se si ha già un puntatore valido alla destinazione, si può passare quello:

int numero;
int *p = &numero;
scanf("%d", p);

Non serve &p: sarebbe l'indirizzo della variabile puntatore, non quello dell'intero in cui si vuole scrivere.

E per le stringhe?

char nome[31];
scanf("%30s", nome);

Qui nome viene convertito in un puntatore al primo elemento dell'array, quindi fornisce già l'indirizzo richiesto da %s. Per leggere un singolo elemento: scanf("%c", &nome[0]);.

La regola corretta

Non è «scanf vuole sempre &», ma «bisogna fornire un puntatore del tipo richiesto dalla conversione».

12. Puntatori a strutture e operatore ->

Con una struttura si usa il punto:

Dipendente dip;
dip.stipendio = 1500;

Con un puntatore a una struttura:

Dipendente *p = &dip;

(*p).stipendio = 1800;   /* forma estesa */
p->stipendio = 1800;     /* forma abbreviata, equivalente */
Hai…Scrivi
una strutturastruttura.campo
un puntatore a strutturapuntatore->campo

Le parentesi in (*p).stipendio servono a dereferenziare p prima di selezionare il campo.

13. Esempio pratico: lavoratori e management

Archivio di 300 lavoratori, di cui si vogliono raggiungere rapidamente i 10 dirigenti. Duplicare i dirigenti in un secondo array di strutture ha un difetto: quando cambia uno stipendio, vanno aggiornate entrambe le copie. La soluzione vista a lezione usa invece un array di puntatori.

Lavoratore datiLavoratori[300];
Lavoratore *management[10];

Lavoratore *management[10]; significa «array di 10 puntatori a Lavoratore». Collegamento:

management[0] = &datiLavoratori[7];
management[1] = &datiLavoratori[42];

I dati restano nell'archivio principale; il secondo array offre un accesso selettivo agli stessi oggetti. Se si modifica datiLavoratori[7].stipendio = 2000;, allora management[0]->stipendio restituisce 2000, perché raggiunge la stessa struttura.

Per la ricerca si visitano solo i dirigenti già selezionati, senza ricontrollare tutti i lavoratori. Il vantaggio deriva dall'organizzazione dei riferimenti, non dal fatto che -> renda il programma più veloce.

14. Puntatori validi, non inizializzati e NULL

Dichiarare un puntatore non crea automaticamente un oggetto a cui accedere.

int *p;
*p = 10;   /* ERRORE: p non è stato inizializzato */

Prima di dereferenziare bisogna assegnare un riferimento valido:

int x;
int *p = &x;
*p = 10;

Un puntatore può essere inizializzato a NULL per indicare che non punta a nessun oggetto:

int *p = NULL;
*p = 10;   /* Comportamento indefinito */

NULL è un valore sentinella, non uno spazio di memoria in cui scrivere.

15. Array e puntatori: collegati, ma non identici

È il punto più delicato della lezione.

int a[4] = {10, 20, 30, 40};
int *p = a;
int *p = &a[0];   /* equivalente: stesso indirizzo */

Nella seconda riga a viene convertito in un puntatore al primo elemento. Ma un array non è una variabile puntatore: il fatto che molte espressioni convertano l'array in puntatore non rende i due oggetti intercambiabili.

Cosa si può modificare?

p = a + 1;   /* Corretto: cambia il puntatore p */
p++;         /* Corretto, se resta nei limiti */

a = p;       /* Errore */
a = a + 1;   /* Errore */
a++;         /* Errore */

Gli elementi dell'array sono modificabili; l'intero array non può comparire come destinazione di un assegnamento.

Il caso confuso nella trascrizione

int a[3] = {1, 2, 3};
int b[3] = {4, 5, 6};
a = b;          /* Errore */

int *p = a;
int *q = b;
p = q;          /* Corretto: entrambi puntano a b[0] */

Solo il secondo esempio è un assegnamento tra puntatori.

16. sizeof: quanti byte occupa un oggetto?

sizeof è un operatore che restituisce la dimensione in byte di un tipo o di un oggetto.

int a[5];
sizeof(int)
sizeof(a[0])
sizeof(a)

Se sulla macchina considerata sizeof(int) vale 4:

EspressioneRisultato
sizeof(int)4
sizeof(a[0])4
sizeof(a)20

Il valore 4 per int è un'ipotesi dell'esempio, non una costante universale del linguaggio.

Con un puntatore, int *p = a;, sizeof(p) misura il puntatore, non l'array raggiunto. È una differenza concreta tra array e puntatori: applicando sizeof direttamente all'array non avviene la normale conversione al puntatore al primo elemento.

printf("%zu\n", sizeof(a));

Il formato %zu è quello adatto al tipo restituito da sizeof.

17. Aritmetica dei puntatori

Aggiungere 1 significa passare all'elemento successivo

int a[4] = {10, 20, 30, 40};
int *p = a;

p       /* Indirizzo di a[0] */
p + 1   /* Indirizzo di a[1] */
p + 2   /* Indirizzo di a[2] */

L'incremento è misurato in elementi del tipo puntato, non in byte. Se un int occupa 4 byte, passare all'elemento successivo significa avanzare di 4 byte; se si punta a strutture, il passo è la dimensione di una struttura.

Equivalenza tra indici e dereferenziazione

Equivalenze da ricordare

a[i] equivale a *(a + i), e &a[i] equivale a a + i.

Per esempio a[2] e *(a + 2) valgono entrambi 30.

La notazione con le parentesi quadre è solo un modo più immediato per esprimere lo stesso accesso.

Sottrarre due puntatori

Se i puntatori appartengono allo stesso array, la sottrazione misura la differenza di posizione in elementi:

int a[5];
int *p = &a[4];
int *q = &a[1];

p - q   /* 3 */
q - p   /* -3 */

Non si ottiene il numero di byte, né il numero di elementi strettamente compresi tra le due posizioni: si ottiene la differenza degli indici.

Refuso nella slide

Nella slide con gli indirizzi 1004 e 1000 (elementi da 4 byte) è p - q a valere 1; la scritta q - p è un refuso, segnalato anche dal docente.

Operazioni consentite e limiti

  • puntatore più intero;
  • puntatore meno intero;
  • differenza tra puntatori appartenenti allo stesso array;
  • confronti tra puntatori, rispettando le condizioni previste dal linguaggio.

Non si possono sommare due puntatori: p + q non è consentito. Percorrendo un array si può arrivare fino al puntatore subito dopo l'ultimo elemento, utile come limite del ciclo, ma non lo si può dereferenziare. Sottrazioni e confronti d'ordine tra oggetti non collegati non vanno trattati come normale aritmetica su numeri.

18. Inizializzazione degli array e dimensioni variabili

Nella dimostrazione finale il docente prova:

int dim = 4;
int arr[dim] = {1, 2, 3, 4};   /* rifiutato dal compilatore */

Poiché dim è una variabile, si sta dichiarando un array a lunghezza variabile (VLA), che non può usare una lista di inizializzazione. Non è un compilatore «poco intelligente»: è una regola del linguaggio.

Dimensione costante e inizializzazione immediata

#define DIM 4
int arr[DIM] = {1, 2, 3, 4};

Qui la dimensione è un'espressione costante e l'inizializzazione è valida.

Dimensione variabile e riempimento successivo

Nel contesto C con supporto ai VLA usato a lezione:

int dim = 4;
int arr[dim];
for (int i = 0; i < dim; i++) {
  arr[i] = i + 1;
}

Prima si crea l'array, poi si assegna un valore a ogni elemento. La dimensione non cambia se in seguito cambia il valore di dim.

Inizializzazione e assegnamento non sono la stessa operazione

int arr[4] = {1, 2, 3, 4};   /* Valido: inizializzazione */

int arr[4];
arr = {1, 2, 3, 4};          /* Non valido: assegnamento */

19. Esercizio d'esame: conversione da base 10 a un'altra base

Si applica l'algoritmo delle divisioni successive: dividere per la base, memorizzare il resto, proseguire con il quoziente, leggere i resti in ordine inverso.

Esempio — $26_{10}$ in base 16
  • $26 \div 16$: quoziente 1, resto 10;
  • $1 \div 16$: quoziente 0, resto 1.

Resti prodotti: 10, 1. Lettura inversa: 1, 10. La cifra 10 in esadecimale è A, quindi il risultato è $1A_{16}$.

La tabella dei simboli converte ogni resto nel carattere corrispondente:

char simboli[] = "0123456789ABCDEF";

simboli[0]    /* '0' */
simboli[10]   /* 'A' */
simboli[15]   /* 'F' */

Cuore dell'algoritmo

Assumendo numero positivo, base tra 2 e 16 e array abbastanza capiente:

int i = 0;
while (n > 0) {
  resti[i] = n % base;
  n = n / base;
  i++;
}

Alla fine i indica la prima posizione libera, quindi l'ultima posizione occupata è i - 1. Stampa inversa:

i--;
while (i >= 0) {
  printf("%c", simboli[resti[i]]);
  i--;
}
printf("\n");

Il passaggio chiave è simboli[resti[i]]: prima si recupera il resto numerico, poi lo si usa come indice per scegliere il simbolo. Così si evita una lunga sequenza di if per distinguere le cifre.

Limiti da non dimenticare

  • Con n == 0 il ciclo non parte: bisogna stampare esplicitamente 0.
  • Con base 1, dividere un numero positivo per 1 non lo riduce: l'algoritmo non termina.
  • L'array deve avere spazio sufficiente per tutti i resti.
  • Il procedimento modifica n: conservare una copia se serve il valore iniziale.
  • Gli interi negativi richiedono una gestione ulteriore del segno.

Per questo algoritmo l'intervallo delle basi è da 2 a 16, non da 1 a 16 come compare in un passaggio della trascrizione.
